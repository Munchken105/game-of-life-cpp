# Conways Game of Life in C++.

The implementation is a fixed array implementation this was for me to learn the basic syntax of c++.


## How to use
1. you can run the main.exe file directly in terminal do .\main this should run the game
2. to choose what cells you want alive or dead you can write row,col in the terminal for example: 2,5. for each cell you want alive and dead you have to enter it mannualy
3. sit back and enjoy the game of life
